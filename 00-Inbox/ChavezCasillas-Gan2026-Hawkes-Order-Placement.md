# Optimal Order Placement under a State-Dependent Hawkes Process LOB model

## Abstract (summarized — arxiv.org unreachable from this environment; verify at url)
Market-making/order-placement stochastic control where market-order arrivals follow a *state-dependent Hawkes process* (replacing Bernoulli/Poisson arrivals in the Cartea-Jaimungal framework). Block-based linear demand links order counts to executed volume; continuous-time dynamic programming with quadratic terminal inventory penalty yields inventory-dependent quotes via backward recursions for a quadratic value function. Numerical experiments on LOBSTER data study quote distributions, inventory exposure, and terminal wealth. Submitted 2026-10-27; 44 pp.

Directly extends [[Market Maker Inventory Control]] with realistic arrivals from [[Hawkes Processes for Order Flow]] — exactly the model intersection both atoms flag as the modern direction. LOBSTER calibration makes it testable.
