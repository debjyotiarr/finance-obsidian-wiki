## Workflow
1. Papers land in `00-Inbox/` (agentic sweep → hand-pick).
2. Each kept paper gets a literature note in `10-Literature/`.
3. Ideas are distilled into atomic notes in `20-Atoms/` and linked.
4. Promising combinations graduate to `30-Signals/` as signal candidates.

See the repository README for the full operating manual and `PLAN.md` for what's left to build.
