# Signals

Signal candidates: combinations of atoms promoted into testable hypotheses. Use `90-Meta/templates/Signal Candidate Template.md`.

A signal note is the bridge from the vault to actual research code — it should contain everything needed to brief a backtest, and a status log of what happened.

New candidates come from the recombine pass (`pipeline/recombine_prompt.md`). First four, created 2026-11-04:

- [[Gamma Regime Conditioned Intraday Momentum]] — intraday, futures/equities
- [[OFI Gated by Flow Toxicity]] — seconds, futures (HFT-class)
- [[Close Auction Imbalance vs Leveraged ETF Flows]] — intraday close, equities
- [[Option Flow Informed Reversal Gate]] — 1-5 days, equities/options
